---
title: "Tag"
tags: [tag]
description: "A meta-tag applied to tag description pages in the AcehWiki, identifying them as documentation about the tagging system itself."
---

A **tag** in the AcehWiki is a keyword applied to entries to group them by subject, theme, region, period, or entity type. Each tag has a dedicated description page (like this one) explaining its scope. This meta-tag identifies pages that are themselves tag descriptions.
