**Individueel restrictiesysteem** (English: "Individual restriction system (rubber)") is a term or concept described in [[J. Jongejans|Jongejan]]'s *Land en Volk van Atjeh Vroeger en Nu* in relation to [[Aceh]]. System introduced for the Noord-Sumatra blok (Atjeh, S.O.K., Tapanoeli) reviving native rubber cultivation; each holder's quota set by tappable trees and government-set restriction percentage.

## Translation

Individual restriction system (rubber)

## Description

System introduced for the [[Noord-Sumatra]] blok (Atjeh, [[S.O.K.]], [[Tapanoeli]]) reviving native rubber cultivation; each holder's quota set by tappable trees and government-set restriction percentage.

## Significance

The term *Individueel restrictiesysteem* is recorded by [[J. Jongejans|Jongejan]] as part of the cultural, administrative, or institutional vocabulary of [[Aceh]].
